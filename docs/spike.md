# Этап 0. Спайк: доказать монтирование через CD-ROM Image

Цель — снять **главный риск проекта** до написания кода: доказать, что BMC
забирает ISO с нашей раздачи и что монтирование выполняется программно, без
вебморды.

Всё делается на боевой машине **без единой перезагрузки**. Монтирование
виртуального медиа подсовывает работающей ОС новый `/dev/sr0` — на сервере без
десктопа это того же порядка, что воткнуть флешку: диски, сеть и запущенные
сервисы не задеваются.

Обозначения: `BMC_IP` — адрес BMC, `HOST_IP` — адрес `itsg-vpn` (тот, который
видит BMC).

## Установленные факты

- `X11DPL-i`, BMC FW `1.76`. BMC стоит на публичном адресе в сети /29, шлюз
  прописан — маршрут наружу есть.
- **Virtual Media → CD-ROM Image присутствует.** Поля Share host, Path to
  image, User, Password; кнопки Save / Mount / Umount; три слота Device 1–3.
- **Режим HTTP/HTTPS поддерживается** — в требованиях прошивки указано
  `Input http://Domain, https://Domain, or just Domain`. Поэтому Samba не
  используется, раздача идёт по HTTP. SMB остаётся запасным путём, если
  HTTP-режим на этой прошивке окажется нерабочим.
- **Жёсткий лимит образа — 4.7 ГБ.** Заявлен прошивкой на самой странице.
- **Порт в адресе указать нельзя.** Разрешённые символы Share host: `a-z`,
  `A-Z`, `0-9`, `-`, `.` — двоеточия среди них нет. Раздача обязана слушать
  порт 80 или 443.
- Побочные находки по безопасности BMC — в [`bmc-hardening.md`](bmc-hardening.md).

---

## Шаг 1. Проверить размер образа

Лимит 4.7 ГБ попадает точно в Windows Server: 2019 около 5 ГБ, 2016 около
6.5 ГБ. Ubuntu Server и Debian проходят с запасом.

```
ls -lh /путь/к/образу.iso
```

Если образ не влезает — брать другой либо ужимать `dism /export-image`,
выкидывая лишние редакции из `install.wim`. Для спайка достаточно взять
заведомо маленький образ, например Debian netinst.

## Шаг 2. Заменить просроченный сертификат BMC

Чинит исходную поломку Java-виджета (`stunnel: certificate has expired`) и
попутно HTML5. Перезагружается **только BMC**, хост не моргнёт.

```
openssl req -x509 -newkey rsa:2048 -nodes -keyout ipmi.key -out ipmi.crt -days 3650 -subj "/CN=BMC_IP"
```

Пару файлов залить в вебморде: **Configuration → SSL Certification**. BMC
перезапустится примерно за минуту. От остального спайка не зависит, можно
делать в любой момент.

## Шаг 3. Поднять раздачу образа

Сначала посмотреть, что уже занимает 80-й порт:

```
ss -lntp | grep -E ':80 |:443 '
```

Почти наверняка там nginx. Тогда раздачу вешаем на него — отдельный сервис
поднимать не нужно и нельзя, порт один.

Каталог с образами:

```
mkdir -p /opt/iso
```

Location в конфиг nginx (в существующий server-блок на 80 порту):

```nginx
location /iso/ {
    alias /opt/iso/;
    autoindex off;
    # на время спайка ограничение по адресу дублирует nftables
    allow BMC_IP;
    deny all;
}
```

```
nginx -t && systemctl reload nginx
```

Проверить локально, что файл отдаётся целиком и с правильным размером:

```
curl -sI http://127.0.0.1/iso/test.iso
```

В ответе должен быть `200` и корректный `Content-Length`.

## Шаг 4. Открыть 80-й порт только для BMC

Та же схема, что пойдёт в продакшен: named set с таймаутом, ядро закроет порт
само, даже если сервис упадёт.

```
nft add table inet ikvm
```
```
nft add set inet ikvm allow '{ type ipv4_addr; flags timeout; }'
```
```
nft add chain inet ikvm input '{ type filter hook input priority -10; policy accept; }'
```
```
nft add rule inet ikvm input tcp dport 80 ip saddr @allow accept
```
```
nft add element inet ikvm allow '{ BMC_IP timeout 4h }'
```

Правило `drop` для 80-го порта на время спайка не ставим — иначе рискуем
отрезать себе же доступ к панелям парка. Ограничение доступа к образам делает
`allow`/`deny` в nginx из шага 3.

## Шаг 5. Смонтировать руками и снять запросы

**До нажатия кнопок** открыть DevTools → Network, включить *Preserve log*,
очистить список.

Параллельно на `itsg-vpn` запустить перехват — это единственный способ отличить
«BMC не дошёл» от «BMC дошёл, но не понял путь»:

```
tcpdump -ni any host BMC_IP and port 80
```

В вебморде **Virtual Media → CD-ROM Image**:

- **Share host:** `http://HOST_IP` — без порта, порт указать нельзя.
- **Path to image:** `/iso/test.iso`. Если прошивка не примет прямой слэш —
  пробовать `\iso\test.iso`; в SMB-режиме формат именно такой, для HTTP не
  документирован. **Записать, что сработало.**
- **User / Password:** пусто.

Нажать **Save**, затем **Mount**, затем **Refresh Status** — Device 1 должен
перестать показывать `No disk emulation set.`

Затем экспортировать лог как HAR и сохранить в `docs/har/`.

> **HAR содержит пароль от BMC в открытом виде** — в теле запроса к
> `login.cgi`. Каталог `docs/har/` внесён в `.gitignore`; в репозиторий эти
> файлы попадать не должны ни при каких обстоятельствах.

Что ищем в HAR:

- `POST /cgi/login.cgi` — как передаются логин и пароль, что возвращается
  (ожидаемо cookie `SID`).
- `POST /cgi/op.cgi` — сохранение настроек образа и собственно Mount. Это и
  есть искомый API.
- Запрос, которым морда опрашивает статус — понадобится для автопродления TTL
  и для живого статуса в интерфейсе.

Если пакетов на `tcpdump` нет вовсе — BMC до хоста не дошёл, дело в маршруте
или фильтрации по дороге, а не в настройках раздачи.

## Шаг 6. Доказать цепочку по данным

В работающей ОС целевого сервера:

```
lsblk && dmesg | tail -20
```

Должно появиться новое устройство `/dev/sr0`.

```
mkdir -p /mnt/vcd && mount -o ro /dev/sr0 /mnt/vcd && ls /mnt/vcd
```

Если файлы образа читаются — доказана вся цепочка: nginx → BMC → эмуляция
USB-CD → реальные байты. Непроверенным остаётся ровно один пункт: выберет ли
BIOS это устройство при загрузке. Проверяется по факту проведения работ, риск
принят (см. `DECISIONS.md`).

## Шаг 7. Воспроизвести curl-ом

Повторить последовательность из HAR без браузера: логин → сохранение настроек
образа → Mount → статус → Unmount.

**Это критерий успеха спайка.** Воспроизводится — драйвер подтверждён, пишем
этап 1. Не поддаётся (одноразовые токены, привязка к сессии,
недетерминированные поля) — возвращаемся к выбору драйвера в `DECISIONS.md`.

## Шаг 8. Убрать за собой

```
nft delete element inet ikvm allow '{ BMC_IP }'
```

Размонтировать образ в вебморде. Location в nginx оставить или убрать по
ситуации — в этапе 1 раздача переезжает в контейнер.
